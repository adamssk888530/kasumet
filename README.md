# KASUMET Homepage

This is a mobile-first KASUMET Virtual Market homepage based on the supplied reference image.

## Structure

- `index.html` — homepage
- `css/style.css` — full visual styling
- `js/market3d.js` — interactive market viewport controls
- `js/app.js` — basic homepage interactions
- `assets/kasumet-reference.png` — supplied reference visual

## Run

Open `index.html` in a browser, or deploy the folder as a static site.

For GitHub Pages, upload the files to a repository and enable Pages from the repository settings.
